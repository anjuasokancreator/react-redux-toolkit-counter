# React Redux Toolkit Counter App

A simple React application demonstrating global state management using
Redux Toolkit. The app includes a counter and basic authentication state
to showcase multiple Redux slices.

## Features
- Global counter state using Redux Toolkit
- Increment, decrement, and increase-by-value actions
- Toggle counter visibility
- Basic authentication state management
- Modular Redux slices

## Tech Stack
- React
- Redux Toolkit
- React Redux
- HTML5
- CSS3

## Concepts Used
- configureStore
- createSlice
- Multiple reducers (counter & auth)
- useSelector & useDispatch
- Centralized state management
